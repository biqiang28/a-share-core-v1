# A股二板成核2.2｜手机网页原型 V1.0

这是**可部署的程序原型**，不是已经上线的网页，也未通过真实行情接口端到端验证。

## 已实现
- 点击按钮尝试通过 AkShare 免费接口读取指定日期的东方财富涨停池。
- 从接口 `连板数` 字段筛选连续二板（须自行核对接口语义和当日数据完整性）。
- 按行业（不是概念题材）汇总涨停数量、二板数量。
- 显示封板时间、炸板次数、换手率等可获得字段。
- 对封板时间和炸板次数给出**局部参考得分**，不冒充完整100分。
- 数据缺失、接口失败时停止给出交易信号；第三层始终标记待核实。
- 下载候选CSV。

## 未实现
- 自动识别细分题材、新闻催化、真实板块同步。
- 100分完整成核评分、唯一核心确认。
- 1分钟分时、Level-2撤单与实时买点提醒。
- 自动交易、自动后台扫描。

## 手机上部署（需要 GitHub 账号）
1. 在 GitHub 新建仓库，把 `app.py` 和 `requirements.txt` 上传到仓库根目录。
2. 打开 https://share.streamlit.io/ ，登录并连接 GitHub。
3. Create app → 选择仓库 → 主文件填 `app.py` → Deploy。
4. 部署成功后，用 iPhone Safari 打开分配的网址，选择日期并点击「开始自动筛选」。

提示：免费行情接口依赖第三方网页，可能随时变化、被限流或在云平台不可访问。部署前后均需测试，不能保证无故障。

## 本地运行（以后有电脑时）
`pip install -r requirements.txt`
`streamlit run app.py`

仅供研究与模拟验证，不构成买卖建议。
